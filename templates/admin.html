Jitsi meeting links

When an event type's location is "Jitsi (auto-generated room)", Cascade builds a fresh room URL per booking from the pattern below. No external API call is involved.

Status {% if jitsi_configured %}enabled{% else %}disabled{% endif %} {% if jitsi_base_url %} Base URL {{ jitsi_base_url }} {% endif %}
Leave empty to disable Jitsi auto-generation.
Shown to guests on the slot picker and booking form. Defaults to "Video call".
Tokens: {username} host, {event} event type slug, {date} YYYYMMDD, {random} 8 characters. Default: {{ jitsi_default_pattern }}.
Without {random} the room name is predictable: two guests booking the same event type on the same day land in the same room and can see each other's meeting. Stable rooms are legitimate — one personal room per host — but only enable this if that trade-off is intended.
